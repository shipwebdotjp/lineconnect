# イベントログ
受信したWebhookイベントログを表示します。イベントタイプや送信元、メッセージの内容、受信日時などを確認できます。

一覧の上部では、イベントタイプ・ソースタイプ・チャネル・メッセージタイプで絞り込みできます。検索ボックスはメッセージ内容を対象に検索します。

| 項目名 | 内容 |
|---|---|
| 選択チェックボックス | 複数行を選択して一括削除するためのチェックボックス |
| ID | イベントログの連番。行アクションから削除できます |
| イベントID | 受信したwebhookイベントID |
| イベントタイプ | 受信したwebhookイベントタイプ |
| ソースタイプ | 受信したwebhookイベントソース（受信した場合はuser、送信した場合はbot） |
| ユーザーID | 受信元/送信先ユーザーID（フォローイベントが発生したユーザーの場合は表示名）<br />ホバー時に出る「メッセージ」リンクをクリックすると、そのLINEユーザーへダイレクトメッセージを送信する画面へ遷移します。 |
| BOT ID | 受信したチャネル。登録済みのチャネルの場合はBOT IDではなくチャネル名を表示します |
| メッセージタイプ | イベントタイプが「message」の場合のメッセージのタイプ |
| メッセージ | メッセージのテキスト、ファイルパス、ポストバックデータ、スタンプ/テンプレートの代替テキスト |
| 受信日時 | webhookイベントの受信日時 |

# フィルターフック
他のプラグインやテーマの `functions.php` で機能を追加したり、設定に変更を加えるためのフィルターフックが用意されています。

以下のグループから選んでください。各グループページの先頭には、そのページで扱うフック一覧があり、続けて各フックの詳細を説明しています。

- [アクション関連フィルター](./actions/): AI応答やトリガーで使う独自アクションを登録します。
- [投稿通知関連フィルター](./post-notification/): 投稿編集画面と投稿公開時のLINE通知設定を変更します。
- [メッセージ送信関連フィルター](./message-sending/): 通知メッセージの引数や送信直前のメッセージを変更します。
- [WPユーザー代替フィルター](./wp-user-alternative/): WordPressのユーザー関連処理を代替実装へ切り替えるフック群を確認します。
- [スキーマ関連フィルター](./schema-related/): 管理画面やフォームで使うスキーマとUIスキーマを調整します。
- [設定関連フィルター](./settings-related/): プラグイン設定、チャネル設定、管理コマンドを調整します。
- [翻訳関連フィルター](./translation-related/): React JSON Schema Form の翻訳文字列をカスタマイズします。
- [トリガー関連フィルター](./trigger-related/): トリガーフックの登録やアクションフック引数の前処理を拡張します。
- [インタラクション関連フィルター](./interaction-related/): インタラクション定義、セッション、応答メッセージをカスタマイズします。
- [HTTPクライアント関連フィルター](./http-client-related/): LINE Bot のHTTPクライアント実装を差し替えます。
